# Description

Changes how fast the camera zooms toward (or away from) your character when you scroll with the
mouse wheel or the gamepad camera zoom.

The speed is a multiplier set in `BepInEx/config/orax.ZoomSpeed.cfg`, editable in game with
ConfigurationManager:

```ini
[Zoom]
## Mouse wheel zoom speed multiplier (1 = vanilla).
## Acceptable values: 0.1 to 10
ScrollMultiplier = 2
```

# Installation

This mod is client-side only.

## Using a mod manager (recommended)

You can install the mod using Vortex (nexusmods.com) or Gale (hexium.gg).

## Manual

Install BepInExPack for Valheim. Copy the DLL file to
`Steam\steamapps\common\Valheim\BepInEx\plugins\`
